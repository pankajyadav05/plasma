round 02 · five wild directions · 2026-04-10

Plasma

Five genuinely different aesthetic territories for the same database client. Round one was too tame and too lo-fi. This round each mockup carries real ambient motion, layered depth, and a point of view I'd be willing to defend in a meeting. None of them look like a normal dev tool. That's the point.

A

Iridescent

holographic · animated mesh · glass jewelry

The accent color literally shifts hue as you sit with it. The wordmark is a holographic foil. Panels are real stacked-blur glass over a slowly-cycling gradient mesh. The Run button catches light like chrome. Bricolage Grotesque + IBM Plex Mono.

→
B

Carson

y2k brutalist magazine · ransom-note typography

David Carson runs a database client. Asymmetric layout, three radically clashing typefaces, flat primary-color blocks, the result grid is rotated 0.4°, the wordmark bleeds off the screen. Numbers in the grid are huge because the data is the point.

→
C

Atlas

victorian specimen catalog · cream paper · brass

A 19th-century botanical atlas became a database client. Cream deckled paper, hand-engraved labels, callout lines pointing at columns like an anatomy diagram, fleurons in the margins, a brass Run plate, a ribbon bookmark on the active tab.

→
D

Console

industrial hardware · amber LED · CRT curvature

The app shell is a physical instrument. Brushed metal bezel, real rivets, ventilation grilles, an LED that pulses while the connection is live. The result grid is a vintage stock-ticker terminal — amber on black, faint scanlines, subtle CRT curvature.

→
E

Greenhouse

organic · hand-drawn · breathing rows

The opposite of every dev tool ever made. Hand-drawn imperfect borders, slow-drifting blob backgrounds, selected rows that gently breathe, botanical illustrated icons for each table. Moss, terracotta, bone, dried lavender. A SQL client for Sunday mornings.
