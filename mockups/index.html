Plasma

5 aesthetic directions · pick one · 2026-04-10

Five completely different visual languages for the same database client. Same content. Same data. Same layout bones. Wildly different typography, color, density, and mood. Click each one. Live with it for thirty seconds. Then pick the one that makes you want to write a query right now.

01

Plasma Terminal

warm dark · electric lime · serif chrome

A modernist scientific instrument. Warm near-black base, a single electric-lime accent used like a laser pointer, italic serif headlines over a brutalist data grid. Geist + Geist Mono + Instrument Serif.

→
02

Paper Editor

cream paper · ink · editorial serif

A research notebook for SQL. Warm cream paper background, deep ink text, oxblood accent. Newsreader serif headlines, DM Sans body, JetBrains Mono data. Comfortable density. The opposite of dark-mode dev tool fatigue.

→
03

Tokyo Midnight

OLED black · cyan + magenta · all monospace

Cyberpunk terminal aesthetic. Pure black for OLED, cool slate text, dual cyan-magenta accents. Everything in JetBrains Mono including the UI labels. Maximum density. Scanline overlay. Made for the developer who lives in the dark.

→
04

Atelier

swiss white · heavy borders · vermilion

Brutalist Swiss editorial design applied to a database tool. Stark white, heavy 2px black borders, single vermilion accent, big uppercase labels, exposed grid. Space Grotesk + Söhne Mono. Like Werkplaats Typografie made you a SQL client.

→
05

Glass Carbon

frosted glass · electric blue · sci-fi cockpit

Apple Vision Pro meets Tron. Carbon-dark base with subtle noise, frosted glass panels with backdrop blur, electric blue accent, generous shadows, gently rounded corners. Inter Display + JetBrains Mono. Layered, atmospheric, futuristic.
