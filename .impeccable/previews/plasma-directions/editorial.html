Different kinds of data.
The same place to work.

Plasma gives each engine its own workspace, without asking you to learn a different application.

Postgres

Write SQL with schema completions. Inspect results, relationships and query plans.

Redis

Browse namespaces. Read typed values, inspect TTLs and open the command line.

OpenSearch

Search documents with query strings or DSL. Choose fields and read index mappings.

A time is a number.
A plan tells you more.

See estimated and actual rows, node timings and buffer reads in the EXPLAIN tree. ANALYZE executes your query.
